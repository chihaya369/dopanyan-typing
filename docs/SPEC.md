# ドパにゃん！ 脳汁タイピング — 仕様書（v1.0）

本書は「ドパにゃん！ 漢字編」（以下「漢字編」）の仕組みを土台に作る、タイピング練習ゲームの仕様です。**本書に書いていない事項は漢字編と、その元になった「ドパドリル」の仕様を引き継ぎます**（ゲームオーバーなし、まちがえても勢いを落とさない、記録は端末内だけ、など）。

---

## 0. 名称と位置づけ

| 項目 | 決定 |
| --- | --- |
| 名称 | **ドパにゃん！ 脳汁タイピング**（ロゴは「脳汁」を最大に。「のうじる」のふりがなを小さく添える） |
| キャッチコピー | キーふんじゃった！ |
| 対象 | 小学生から大人まで。学校向けの配慮はしない。うまい人ほど脳汁が出る作りにする |
| 位置づけ | 「ドパドリル」（grmchn）の非営利・非公式の改造版。漢字編と同じ権利表記を画面と LICENSE に入れる |
| キャラクター | ギン（シルバー系サイベリアン）とスミ（日本の黒猫）。漢字編の造形・演技をそのまま使う |

## 1. コンセプト

**正しく1打するたびに、ねこがキーを踏み、ねこふんじゃったの次の1音が鳴る。** 打ち続けると自分の指で曲を演奏していることになり、速く正確に打つほど曲は速く、派手に、にぎやかになる。

ほかの人気タイピングソフト（寿司打、プレイグラム タイピング、e-typing、keybr など）には、打鍵そのものが旋律になる仕組みがない。これを本作の看板にする。

## 2. 対応環境と入力方式

### 2.1 入力方式（4種）

| 方式 | 使う場面 | 入力の単位 |
| --- | --- | --- |
| **ローマ字（物理キーボード）** | PC、スマホやタブレットにBluetoothキーボードをつないだとき | 英字1打 |
| **フリック** | スマホ・タブレットのタッチ操作 | 1回のタップまたはフリックで、かな1文字 |
| **画面QWERTY** | スマホでローマ字を練習したいとき | 画面のキー1打 |
| **かな入力（物理キーボード）** | 設定で選んだときのみ | かな1打。第1版では対象外とし、設定に項目だけ用意して「じゅんびちゅう」と表示する |

**OSのキーボード（IME）は使わない。** 変換中は1打ごとの判定ができないため。すべての入力はゲーム内で直接受け取る。

### 2.2 方式の自動選択

- 起動時は、タッチ画面なら**フリック**、そうでなければ**ローマ字**で始める。
- タッチ端末でも、物理キーの入力（英字キーの keydown）を1回受け取ったら、その場で「キーボードが つながったね！ ローマ字モードに するよ」と案内し、ローマ字に切り替える。
- 設定の「にゅうりょく」で、いつでも手動で切り替えられる（ローマ字／フリック／画面QWERTY）。
- 記録・ランキング・星は**入力方式ごとに別**に持つ。速さの基準がまったく違うため。

### 2.3 画面の向き

- **第1版は縦画面のみ。** スマホを横にしたとき（横長かつ高さ500px未満）は、ギンとスミが「たてにしてね」と案内する画面を全面に出して、プレイを一時停止する。
- PCなど十分に広い横長画面では、縦長のゲーム画面を中央に置く（漢字編と同じ）。
- 将来の横画面対応に備えて、「問題カード」「演出エリア」「キーボード」を独立した部品として作り、向きによって配置だけ切り替えられる構造にしておく。

## 3. 画面構成（縦）

上から順に次のように並べる。

1. **ヘッダー**：進み具合、時計、ミュート
2. **数値の帯**：打/秒、正確率、コンボ、ドパ（脳汁の量）
3. **演出エリア**：ギン・スミ・おきゃくさん、背景、紙吹雪など
4. **問題カード**：本文、よみがな、ローマ字ガイド（4章）
5. **キーボードエリア**：入力方式により中身が変わる
   - ローマ字（物理）：**ガイドキーボード**を表示する。押すべきキーが光り、指の担当色で塗り分ける。ギンが次のキーの上に先回りして座る。画面が狭い場合は、設定でガイドキーボードを隠して演出エリアを広げられる
   - フリック：12キー（6章）
   - 画面QWERTY：10列のQWERTY（7章）

キーボードエリアの高さは、画面の高さの40〜45%を目安にし、最下段は下端の安全領域より上に置く（漢字編と同じ）。

## 4. 問題

### 4.1 表示（3段）

```
 ねこが キーを ふんじゃった        ← 本文（漢字まじり。大きく）
 ねこが きーを ふんじゃった        ← よみがな（ひらがな1行）
 nekoga ki-wo funjatta           ← ローマ字ガイド（ローマ字方式のみ）
```

- **本文**：漢字まじりの文。問題の中身は4.3。
- **よみがな**：打つ内容そのもの。打ち終わった文字は色が変わり、今の文字には下線を引く。ルビ方式はスマホで小さすぎるため使わない。
- **ローマ字ガイド**：ローマ字方式と画面QWERTYで表示する。打ち終わった部分は色が変わり、次の文字が光る。フリックでは表示せず、代わりに次のキーとはじく方向をキーボード上で光らせる。
- 本文とよみがなが同じ（ひらがなだけの問題）場合は、よみがなの段を省く。

### 4.2 ガイドの段階

ガイドはスキルの習熟度に応じて自動で減らす。

| 段階 | 条件 | ローマ字ガイド | ガイドキーボード |
| --- | --- | --- | --- |
| てとりあしとり | そのスキルが「NEW」「練習中」 | 全文を表示 | 次のキーと指を光らせる |
| ひとりだち | マスター後 | 次の1文字だけ表示 | 次のキーだけ光らせる |
| ブラインド | ☆3以上 | 表示しない | 光らせない。キーボードを暗くする |

ただし、同じ位置で2回まちがえたら、その1文字だけ一時的に「てとりあしとり」に戻す。設定で「ガイドを いつも ぜんぶ出す」も選べる。

### 4.3 問題の中身

| 種類 | 出典 | 使い道 |
| --- | --- | --- |
| **かな・音** | 自作（あ、か、きゃ など） | 最初の段階の練習 |
| **単語** | 漢字編の語データ（約4,500語、CC BY-SA 4.0） | 単語の段階 |
| **ねこ文**（主力） | **書き下ろし**。ねこネタ中心の、読むと笑うような短い文。例：「ねこが キーボードで ねている」「ギンの しっぽが もふもふ すぎる」「スミが こっそり にぼしを たべた」 | 短文・長文の段階、エクストラ |
| **にちじょう文** | 書き下ろし。例：「きょうは いい てんきです」 | 短文の段階に2割ほど混ぜる |
| **ことわざ・古い俳句** | 著作権の保護期間が終わったもの | 上級・長文 |

- **使わないもの：** 歌詞、アニメやゲームの台詞、実在の人物・商品名、他社のタイピングソフトの問題文。
- **第1版の量：** ねこ文150、にちじょう文50、ことわざ・俳句50を用意し、後から追加しやすいデータ形式にしておく。
- **1問の長さ：** 画面に2行以内。

### 4.4 問題の長さの段階

| 段階 | 1問の打鍵数（ローマ字換算） | 例 |
| --- | --- | --- |
| おと | 1〜3 | あ、か、きゃ |
| ことば | 4〜12 | ねこ、がっこう |
| みじかい文 | 15〜30 | ねこが ねている |
| ながい文 | 40〜80 | ことわざ、長いねこ文 |

### 4.5 データ形式

```jsonc
{
  "id": "neko-012",
  "text": "ねこが キーを ふんじゃった",   // 本文
  "yomi": "ねこが きーを ふんじゃった",   // 打つ内容（ひらがな・長音・読点・スペース）
  "kind": "neko",                       // kana | word | neko | daily | kotowaza
  "kana": ["ね", "こ", "が", …]          // 自動生成：含まれるかな（7.2 の出題選別に使う）
}
```

- 本文中のスペースは、見やすさのための区切りとして扱い、**打たなくてよい**（よみがなからは自動で除く）。
- 句読点（、。）と長音（ー）は打つ対象にする。ローマ字では「,」「.」「-」、フリックでは読点キーと「わ」キーの右フリックで入力する。

## 5. ローマ字の判定

- 漢字編の `kana.js` のローマ字変換を拡張して使う。1打ごとに、その時点で正解になりうる英字の集合を計算し、含まれていれば正解とする。
- **書き方の揺れはすべて正解にする**（ヘボン式・訓令式・`xtu`／`ltu`・`nn`／`n'`・子音重ねの「っ」など）。
  - 例：「し」は `shi`・`si`・`ci`、「ちゃ」は `cha`・`tya`・`cya`、「ん」は後ろが母音・な行・や行以外なら `n` 1回でもよい。
- **ガイドの表記は、その人がよく使う書き方に合わせる。** ある音で別の書き方が3回続いたら、以後のガイドをその書き方に切り替える。記録は端末内に保存する。
- まちがえた打鍵は画面上に一瞬だけ赤で出して消す。**打った文字は入力として残さない**（元の位置のまま、正しい文字を待つ）。

---

## 6. フリックの判定

### 6.1 キー配列（iPhone・Android の標準と同じ）

```
 [ あ ] [ か ] [ さ ]   [ ⌫ ]
 [ た ] [ な ] [ は ]   [空白]
 [ ま ] [ や ] [ ら ]   [ ⏎ ]
 [小゛゜][ わ ] [、。?!]
```

- **フリックの方向**：タップ＝あ段、左＝い段、上＝う段、右＝え段、下＝お段。
- **や**：左＝「（」、上＝ゆ、右＝「）」、下＝よ。
- **わ**：左＝を、上＝ん、右＝ー。
- **小゛゜キー**：直前の文字を次の順で切り替える。
  - か→が→か
  - は→ば→ぱ→は
  - つ→っ→づ→つ
  - や→ゃ→や
- 指を置いた位置から一定距離（キー幅の35%）以上動いたらフリックと判定する。指を置いている間は、方向の候補を十字形に表示する。

### 6.2 判定

- 1回のタップまたはフリックを1打とする。
- 「が」は「か」＋小゛゜1回、「ぱ」は「は」＋小゛゜2回、「っ」は「つ」＋小゛゜1回で完成する。**完成までの途中の状態（「が」を打つときの「か」など）も正解の1打として扱う**。音・コンボ・ドパも1打分ずつ進める。
- 目標にたどり着けない入力（たとえば「さ」）はミスとする。

---

## 7. 画面QWERTY

- 10列×3段にスペースとBackspaceを加えた、英字のみの配列にする。縦画面での1キーの幅は約35〜39px。そのぶん高さを52px以上取る。
- 押したキーは指の上に拡大表示する（標準キーボードと同じ吹き出し）。
- 判定はローマ字（5章）と同じ。
- QWERTYを選んだとき、1回だけ「ほんものの キーボードが あると もっと うちやすいよ」と案内する。

## 8. 音

### 8.1 3層の構造

**① 旋律（プレイヤーが弾く）**
- 正しく1打するたびに、ねこふんじゃったの旋律を1音進めて鳴らす。**押した瞬間に鳴らし、拍に合わせて遅らせない。**
- まちがえた打鍵では旋律を進めず、スミの「ふにゃ」（漢字編の鳴き声）を鳴らす。
- 旋律の位置は問題をまたいで引き継ぐ。1周（約80音）したら頭に戻り、1周ごとに転調する（8.3）。
- 旋律のデータは漢字編の `audio.js` にある16小節の採譜（右手の上声と左手の単音）から、1打ごとに鳴らす音の列を作る。和音で鳴る箇所は、和音ごと1打で鳴らす。

**② 伴奏（自動で流れる）**
- ドラムとベースは、時計どおりに流し続ける。
- 和音（コード）は**時計ではなく、プレイヤーが今いる旋律の位置で決める。** これにより、打つのが速くても遅くても旋律と伴奏がぶつからない。
- 数秒間打たないでいると、伴奏はドラムだけに薄くなって待つ。打ち始めると元に戻る。

**③ 盛り上がり（脳汁の段階）**

漢字編の演出段階 L（0〜10）を使う。段階が上がるたびに、次の順で音を重ねていく。

| L | 追加する音 |
| --- | --- |
| 0〜1 | 旋律と、軽いドラム |
| 2 | ベース |
| 3 | 手拍子とスネア |
| 4 | ハイハット |
| 5 | 旋律にオクターブ上を重ねる |
| 6 | 和音のスタブ |
| 7 | ハモリ |
| 8 | ブラスまたはリード |
| 9 | コーラスとクラッシュ |
| 10 | 全部盛り。ねこの合唱 |

### 8.2 テンポの追従（v1.1で変更）

運動時の音楽研究（120〜140BPMが最もやる気を高め、145BPM付近で頭打ち）に合わせて変更した。

- 通常プレイは **116 → 152BPM** の範囲。立ち上がりは穏やかで、正しい打鍵9回ごとに1BPMずつ上がる（最大+26）。
- 直近5秒の打鍵ペースを加味する（基準は1秒に3打。-6〜+14BPM）。FEVER中は+8。
- エクストラは **132 → 178BPM**（打鍵6回ごとに+1、最大+44）。マタタビ中は×1.1で上限+16。
- 目標値には5%ずつなめらかに近づける。

### 8.2b ミックス（v1.1で追加）

BGMが旋律より大きく、曲が聞こえない問題があったため、オフライン書き出しで音量を測って調整した。
調整前は **伴奏が旋律より最大約15dB大きかった**。

- 伴奏は旋律に対して常に控えめにする。ドラム ×0.45、ベース ×0.5、そのほかの和音・分散・スタブは ×0.2。
- 旋律は ×3.0。さらに編曲ごとの補正（クラシック1.9／8ビット0.45／おまつり2.6／ブラス1.1／エレクトロ2.4）で、
  どの編曲でも旋律が伴奏と同じか少し大きくなるようにそろえた（測定値：旋律−伴奏 = −3〜+2dB）。
- 4秒以上打たないと、伴奏はドラムだけに薄くなる（×0.06）。
- 段階7以上のハモリは1オクターブ下に固定（調から外れない）。

### 8.3 転調と区切り

- **1文を打ち切るたび**に、締めの和音と、ギン・スミの「にゃー」の和音を鳴らす。長い文ほど締めを派手にする（ベルの本数、クラッシュ、コーラス）。
- **旋律が1周するたび**に半音2つ上へ転調する（上限は漢字編と同じ）。

### 8.4 曲のコレクション

- 初期曲はねこふんじゃった（5種のアレンジは漢字編と同じ）。
- トロフィーで、保護期間の切れた旋律を解放していく。候補は、きらきら星、トルコ行進曲の主題（モーツァルト）、天国と地獄の主題（オッフェンバック）、森のくまさんの原曲（アメリカ民謡）。
- **採譜は保護期間の切れた楽譜から行う。現代の編曲や録音は写さない。**

## 9. 演出（脳汁）

漢字編の演出をすべて引き継ぎ、次を変更・追加する。

| 場面 | 演出 |
| --- | --- |
| 1打の正解 | ギンかスミ（交互）がキーを踏む。旋律の音が鳴る。ドパの小さな加算。音程に合わせて色の変わる♪が飛ぶ |
| 1文の打ち切り | 本文が弾けて紙吹雪になる。はなまる、ドパの大きな加算。長い文ほど大きくする |
| コンボの節目（10・25・50・100・200・…） | 「〇〇コンボ！」のカットインとねこの行進。100以上は画面全体が虹色になる |
| ミス | スミの「ふにゃ」。そのキーが一瞬ぷるっと揺れる。ドパは減らさない |
| スマホの振動 | 正解は短く（10ms）、1文の打ち切りは長め（40ms）。対応端末のみ（AndroidのChromeなど）。iPhoneは非対応。設定でオフにできる |

## 10. スコアと評価

### 10.1 数値

| 項目 | 定義 |
| --- | --- |
| 打/秒 | 正しい打鍵数 ÷ 入力できた時間（秒）。問題の切り替え中は数えない |
| 正確率 | 正しい打鍵数 ÷ 全打鍵数 |
| 脳汁スコア | 1分あたりの正しい打鍵数 × 正確率²（小数点以下切り捨て） |
| ドパ | 漢字編と同じ対数式。1打を1マスとして扱う |
| コンボ | 正しい打鍵で1増え、ミスで0に戻る。時間切れによるコンボ切れは設けない（タイピングは連続入力のため） |

正確率を2乗するのは、速さより正確さを重く見るためです。e-typing（3乗）ほど厳しくはしない。

## 11. モード

| モード | 内容 |
| --- | --- |
| **じぶんレベル** | 漢字編と同じ。初回は実力チェック。以後は解放済み・未マスターのスキルと、さびたスキルの復習から出題する |
| **コース** | 「おと」「ことば」「みじかい文」「ながい文」を選んで練習する（漢字編の学年別にあたる） |
| **にがてキー** | 苦手なキーを多く含む語や文を集めて出題する（12章） |
| **エクストラ** | 基本の初回正解率80%以上で解放。90秒で何打できるかに挑む。テンポの上限240、得点は青天井 |
| **デモ** | 漢字編と同じく自動でプレイする。入力方式に合わせた打鍵を見せる |

1回のプレイは基本6・10・14問（初期値10問）。**制限時間で追い立てない**（打ち切ればクリア）。時間制限はエクストラだけにする。

## 12. スキルツリーと苦手キー

### 12.1 ローマ字のツリー

keybr の「文字を1つずつ解放する」方式を、ツリーの形で行う。**各スキルは、使ってよいキーの集合**として定義し、出題は解放済みのキーだけで打てる語・文から選ぶ。

| レーン | 内容 |
| --- | --- |
| ホーム段 | F・J → A・S・D・K・L・; → G・H |
| 上段 | E・I → R・U → T・Y → W・O → Q・P |
| 下段 | N・M → C・V → B・X・Z → , . |
| 特別 | ん、っ、拗音（きゃ・しゃ など）、長音、読点・句点 |

最後に、すべてを使う「ことば」「みじかい文」「ながい文」のスキルを置く。

### 12.2 フリックのツリー

行ごとに解放していく。

1. あ・か・さ
2. た・な・は
3. ま・や・ら・わ
4. 小゛゜（濁音・半濁音・小書き）
5. 記号と長音
6. ことば → 文

### 12.3 マスターと星

漢字編の規則を引き継ぎ、判定の単位を「1問」とする。

| 状態 | 条件 |
| --- | --- |
| マスター | 直近6問中5問を、ミス0で打ち切る |
| ☆3の速さ | そのスキルの目標打/秒以上 |

目標打/秒は、ホーム段1.5から「ながい文」4.0まで、段階ごとに設定する。

### 12.4 苦手キーの分析

- キーごと（フリックではかなごと）に、平均の打鍵時間とミス率を記録する。直近200打の移動平均。
- 「にがてキー」モードと、じぶんレベルの出題の3割で、苦手な上位3キーを多く含む語・文を優先する。
- 結果画面に「にがてキー TOP3」を、キーボードの図の上に色で示す。

## 13. 結果画面とシェア

- 結果画面の上半分を、スクショ1枚で映える**リザルトカード**にする。
  - 載せる項目：段位、脳汁スコア、打/秒、正確率、最大コンボ、ドパ、ギンとスミの決めポーズ、タイトルロゴ、日付
- 「がぞうで ほぞん」ボタンでカードを画像にする（Canvas で描いて PNG に書き出す）。
  - 対応している端末では共有シートを開く（Web Share API）。対応していない端末では画像をダウンロードする。
- 画像に個人情報は入れない（名前の入力欄は設けない）。

## 14. 継続の仕組み

漢字編の仕組み（カレンダー、ログインシール、ノーカンハンマー、デイリークエスト、トロフィー、コレクション、タイムカプセル、前回とくらべる）をすべて引き継ぎ、次を変更する。

- **ずかん → 「きょくずかん」：** 解放した曲と、その曲を最後まで弾ききった回数を記録する。
- **トロフィーの追加：**
  - 打鍵数の累計
  - 段位の到達
  - 1曲を通して弾ききる（旋律1周をミス0）
  - 最大コンボ
  - 入力方式ごとの段位
- **デイリークエストの追加：** 「1曲 ひききる」「100コンボ」「にがてキーを 20打」。

## 15. 保存

- 保存キーは `dopa-nyan-typing:v1`。漢字編とは別に持つ。
- 入力方式ごとに次を保存する。
  - スキルの進み具合と星
  - キーごとの統計
  - ローマ字の書き方の好み
  - 記録
- 外部への送信はしない。アカウント、広告、ランキングサーバーは持たない（全国ランキングはない。自分の記録との勝負にする）。

## 16. 実装の方針

漢字編のコードを土台にする。

| 部分 | 方針 |
| --- | --- |
| 流用するもの | 画面の骨組み、ギンとスミ、演出（fx・bg）、スコアとドパ、スキルツリー、トロフィー、保存、ガイド、`kana.js` のローマ字変換 |
| 新しく作るもの | 問題カード（3段表示）、ガイドキーボード、フリック12キー、画面QWERTY、入力方式の切り替え、旋律を1打ずつ鳴らす仕組みと位置で決まる伴奏、テンポ追従、キー統計、リザルトカード画像、横画面の案内 |
| 書き直すもの | `problems.js`（語・文データからの出題）、`skills.js`（キー集合によるスキル）、`audio.js`（旋律を1打ずつ進める方式に変更） |
| データ | `data/words.js`（漢字編の語データから作る。CC BY-SA 4.0）、`data/sentences.js`（書き下ろし） |

### 作業の順番

1. 問題カードとローマ字入力の判定（物理キーボード）
2. 旋律を1打ずつ鳴らす仕組みと伴奏
3. フリックキーボード
4. 画面QWERTY
5. スキルツリー（キー集合）と苦手キー
6. 文の書き下ろしとデータ化
7. 段位、リザルトカード、シェア
8. トロフィー、クエスト、曲コレクション
9. 実機での確認（iPhoneのSafari、AndroidのChrome、PCのChrome・Edge、Bluetoothキーボード）

### 受け入れ基準

- 4つの入力方式（物理ローマ字、フリック、画面QWERTY、Bluetoothキーボード）で、それぞれ最後まで遊べる。
- 旋律は、正しく打った数だけ正確に進む。どの打鍵ペースでも伴奏とぶつからない。
- 押してから音が鳴るまでの遅れが体感で気にならない（目安30ms以内）。
- スマホを横にすると案内が出て、縦に戻すと続きから遊べる。

## 17. 試遊後に調整する数値

| 項目 | 初期値 |
| --- | --- |
| テンポ追従の式 | `100 + 12 × (打/秒 − 3)`、下限90・上限180（エクストラは240） |
| 段位の基準 | 10.2の表 |
| 入力方式ごとの係数 | ローマ字1.0、フリック0.8、画面QWERTY0.6 |
| フリックの判定距離 | キー幅の35% |
| ガイドの切り替え条件 | 4.2の表 |
| ローマ字の書き方の学習 | 同じ書き方が3回続いたら切り替え |
| 苦手キーを優先する割合 | じぶんレベルの出題の3割 |
| 目標打/秒 | ホーム段1.5 〜 ながい文4.0 |
